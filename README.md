# 游玩前阅读

## 注意:

推荐在浏览器全屏模式下进行游玩，不然会遇到画面显示不全的问题

浏览器输入下面的地址即可开始游玩~~

```
 https://holy-wax.github.io/NeonHunter/
```

## 基础操作：

**鼠标移动**可以控制挡板移动

按下 **Space(空格)键**  或  **鼠标左键** 时可以改变挡板的颜色

按下 **Esc键** 可以暂停游戏  如果后期小方块下落速度过快可以活用暂停进行帧操

回合结束时可以按下对应的  **字母键** 进行阶段的选择

按下对应的 **数字键** 可以进行buff的选择或下注的数量等，游戏中会有提示引导

挡板的颜色与小方块**颜色相同**时，可以接取小方块并获取金币收益

**漏接**或**错接**会失去生命值，每轮结束后生命值会重置

黄方块漏接不会失去生命值

但是在没有特定的buff时，接取黄方块会扣除生命值
